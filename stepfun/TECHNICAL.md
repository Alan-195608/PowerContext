# 本地知库：一页技术说明

**模型与量化。** 使用 Xenova/all-MiniLM-L6-v2（Apache-2.0），固定 revision `751bff37182d3f1213fa05d7196b954e230abad9`，384维，mean pooling、L2归一化。使用上游发布的 INT8 ONNX，通过 Transformers.js `dtype:q8` 加载；FP32 使用同版本 `model.onnx`。下载脚本及 SHA256 见 `scripts/fetch-model.py` 和 `results/model-sizes.json`。按“权重+共享配置/tokenizer”相同口径，FP32 **91,100,408 bytes**，INT8 **23,685,172 bytes**，压缩比 **3.846×**。不包含运行时 WASM，也不把两种精度同时下载后的总目录体积当单个模型体积。

**端侧运行。** Transformers.js 4.3.2 在浏览器 Worker 执行文档和查询 embedding，显式尝试 WebGPU，检测 adapter 并实际推理预热；不可用或失败时选 WASM，界面显示后端和原因。强制 WASM 可复现降级工作路径。模型预先下载后本地提供，禁止远程模型加载；Node 服务没有 embedding 实现。

**seekdb 与状态。** seekdb-js 1.4.0 默认启动本地嵌入式 seekdb。集合 `sf_<name>_<dtype>` 包含384维 cosine HNSW 与 beng 全文索引，存储原文、向量、文档ID、来源和模型身份。`hybridSearch()` 由数据库执行两路候选及 RRF，最终返回5条原文；前端不做候选融合。来源+片段序号+内容 SHA256 作为 ID，upsert 幂等，按64条写入并合并刷新。导入返回前按ID回读，同集合操作排队。切换知识库清空结果，精度使用独立集合。

**实测条件。** 2026-10-29，北京时间；Apple M4、16GB RAM、macOS 27.0；Codex 内嵌 Chromium（UA Chrome/156.0.0.0，硬件并发10）。自编英文12文档、8查询，每配置3轮，后两轮中位数；Recall/nDCG 为全部查询均值。模型为英文模型，本结果不支持中文质量结论。数据库与浏览器在同一机器，配置为默认嵌入式。原始证据 `results/browser-benchmark.json`；模型文件由 localhost 加载，缓存可能复用，不是互联网冷下载测试。查询端到端截止 API JSON 解析，不包含屏幕绘制。

| 配置（b=推理批大小；写入=每次刷新前片段数） | 文档/秒 | seekdb ms | 查询端到端 ms | 写入+刷新 ms/12文档 | Recall@5 / nDCG@5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| fp32 / wasm / b1 / 写入128 | 78.53 | 1.30 | 10.10 | 492.57 | 1.000 / 0.908 |
| q8 / wasm / b1 / 写入128 | 72.25 | 1.34 | 11.00 | 438.94 | 1.000 / 0.908 |
| q8 / wasm / b8 / 写入1 | 70.84 | 1.36 | 11.30 | 4800.89 | 1.000 / 0.908 |
| q8 / wasm / b8 / 写入128 | 56.56 | 1.31 | 10.60 | 385.38 | 1.000 / 0.908 |
| q8 / webgpu / b8 / 写入128 | 52.15 | 1.34 | 39.60 | 441.14 | 1.000 / 0.908 |

**优化结论。** 同为 INT8/WASM/b8，逐条写入刷新改为合并写入刷新，数据库写入+刷新从 **4800.89ms** 降至 **385.38ms**，约 **12.46×**，下降 **91.97%**，检索质量不变。INT8 减少模型文件体积约74%；此小语料下批推理和 WebGPU 没有吞吐优势，GPU 查询延迟高于 WASM，因此不宣称其加速。首轮计时与模型加载计时均在原始记录中，不能只选最快一轮。

**验证边界。** 已跑浏览器完整评测、真实 seekdb 增量/重复导入、刷新后检索、集合与精度隔离、无效向量及跨站拒绝测试；`npm test`、`npm run build` 通过。强制 WASM 完整流程与实际 WebGPU 完整流程均实测；没有独立禁用 GPU 的设备或 Edge 实测。数据规模小，仅作为可复现功能与性能证据。
