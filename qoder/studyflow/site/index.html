研途 StudyFlow

基于 PowerContext 的学习科研进度助手

记录学习进展、追踪困难与计划、生成确定性周报。所有数据通过 OceanBase PowerContext SDK 持久化存储，每个学习主题对应独立 Scope，实现严格的主题隔离。

PowerContext 真实 SDK Scope 隔离 确定性周报 中文界面

核心功能

📝

学习记录

记录每个主题的进展、困难、下一步计划和备注。数据以 JSON 格式存储在 PowerContext Memory Entry 中，包含稳定 marker 标识。

📅

时间线

按时间倒序展示学习记录，支持按主题筛选。每条记录显示 memory_id 和真实创建时间，便于溯源。

💡

智能建议

基于确定性规则从真实存储生成学习建议：继续上次计划、回顾困难、复习近期进展。不依赖 LLM。

📊

周报生成

自动汇总指定周期内的学习记录，生成 Markdown 格式周报，包含完整 memory_id 引用来源。

🔒

主题隔离

每个学习主题对应独立的 PowerContext Scope，通过 idempotency_key 保证幂等创建，数据严格隔离。

🔄

持久化存储

基于 SQLite 后端的 PowerContext 内置运行时，重启后数据完整保留，字段和时间不变。

Scope 隔离

每个学习主题创建一个 PowerContext Scope，使用 idempotency_key 保证幂等。Scope 之间数据完全隔离，召回时只读取对应 Scope 的 Memory Entry。

Memory Entry 结构

每条记录存储为 JSON 格式的 Memory Entry text 字段，包含 marker: "studyflow:record" 标识、created_at 真实时间戳、进展/困难/计划/备注四个字段。

确定性生成

建议和周报完全由确定性规则从真实存储数据生成，不调用任何 LLM 服务。周报 Markdown 中包含完整 memory_id 引用，可溯源到每条原始记录。
